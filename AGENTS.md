# Agentic Personas Storefront project guidance

Read `.covers/methodology/COVERS.md` before scoped work. Recommend Lite or Full per task; both may coexist. Full work uses the selected active spec and `specs/spec-registry.json`; Lite work uses a note under `specs/quick/` and `.covers/methodology/workflows/lite.md`. Neither record grants execution authority by itself.

## Repository shape and generated files

- pnpm 9.15.0 workspace managed through Corepack; Turborepo coordinates `apps/api`, `apps/web`, and `packages/shared`.
- `apps/web/src/routeTree.gen.ts` is generated by TanStack Router. Change route source files or generator configuration, then regenerate; do not hand-edit it as the primary change.
- Application state is currently in-memory. Never assume production durability, tenant isolation, or release readiness from local behavior.

## Execution boundary

- Preserve unrelated and uncommitted work. Inspect scripts and destinations before execution.
- Do not start services, contact application backends, query external advisory services, install browsers/containers/global tools, enable hooks, commit, push, or deploy without explicit authority.
- Never treat source inspection as reproduction, a zero-test command as verification, or passing checks as proof beyond their tested scope.
- Keep functional/product decisions separate from security-risk acceptance. Before a repair, obtain approval for the intended behavior and covering spec; retain a meaningful failing regression before the fix and a passing regression afterward.
- Keep credentials and real personal data out of source, specs, logs, and prompts.

## Assessment defaults

Use a unit-first initial characterization with existing Node/TypeScript/tsx/Fastify capabilities. Add focused Fastify injection only where it is the lowest faithful layer for authentication or ownership. Defer new browser/E2E infrastructure unless an approved behavior requires it. Track generated output, cache identity, user/account switching, persistence loss on restart, and external avatar loading explicitly.
