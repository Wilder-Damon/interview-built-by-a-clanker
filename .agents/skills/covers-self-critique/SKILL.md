# covers-self-critique

SPEC-TOOL-015/R2: Read workflows/self-critique.md under methodology/ or .covers/methodology/. Use its five-dimension 1–10 rubric and independent finding-resolution loop; the score is not a correctness probability.

For specs with requirements sources, include authorized source content and source-to-acceptance mappings in the review. Identify omissions, contradictions and unverified/inaccessible sources without inventing business intent or expanding access. A structurally valid requirements field is not proof of alignment.

Before acting, read the shared COVERS operating contract: in a source checkout use repository-root methodology/COVERS.md; in an adopted project use repository-root .covers/methodology/COVERS.md. If unavailable, report the missing contract rather than inventing rules. This skill is distributed with the toolkit, not as a standalone file.

Accept evidenced review by a qualified non-author human or, when authorized,
delegate to an independent available subagent with raw artifacts and constraints,
not a desired conclusion. If you are already that delegated reviewer, perform the
review directly; do not recursively delegate. No available subagent does not
invalidate an existing human review. If neither reviewer is available, disclose
the missing checkpoint. An explicitly requested review stays pending unless the
requester authorizes deferral; an author's self-check is not a substitute.

Use the shared five-dimension rubric for specs; separate readiness/blockers from
score. Findings need IDs, evidence, severity, consequence and closure checks.
Correct only within current authority and covering spec; review-only stays read-only.
Re-review corrections independently and report dispositions. Do not iterate for
cosmetic perfection or confuse structural checks with behavioral validation.

Use the existing project specs/ registry and invariant catalog; do not assume personal/global skills or credentials exist. The user's scope and higher-priority instructions always bound these procedures.
